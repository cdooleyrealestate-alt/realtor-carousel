# Acceptance scenarios
Missing script: ask for it, no fictional batch.
Short label: 10 usable standalone images, default 9:16.
Long label: 20, default 16:9; explicit ratio overrides.
1980s same kitchen: reference edit retains geometry with oak/laminate/linoleum/brass/white appliances.
Real listing: source photos and virtual-change disclosure.
No attachment transport: generation and upload status reported separately.
Interrupted 7/10: resume remaining three without duplicate records.
Selected scenes 2/6, revise 4: preserve selections and create one new scene-4 version.
Full new batch: N new assets and intact originals.
Upload retries: stable ID lookup, no duplicate creation.
Ready: read-back attachment verification.
No background service: feedback read only when invoked.


New creator: ask platform/new-or-existing, create or connect their own destination, never author base.
Notion unavailable: report missing connection; no false page creation.
Sheets private asset: working file link, no public sharing to force thumbnail.
Returning creator: read setup and feedback; do not create duplicate workspace.
